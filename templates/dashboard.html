How the System Works

1

Data Collection

TCS historical stock data is collected from Yahoo Finance.

2

Preprocessing

Closing prices are scaled using MinMaxScaler and converted into 60-day sequences.

3

GRU Model

The GRU network learns relationships between previous stock prices.

4

Prediction

The trained model predicts the next trading day's closing price.
